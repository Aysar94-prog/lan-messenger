# CALLCAPS records:  name|expectCapable|verified|legacy|elapsedMs|reply
#   The reply field uses \t and \n escapes; a leading '-' means "the peer sent nothing at all"
#   (no reply, connection closed before an answer), which is the common real-world case.
#
# CALLGRANTS records: name|expectMask|reply
#   expectMask is 0..15, or -1 for "no usable answer at all"
#   a '-' reply means the peer closed the connection without answering, which is a NULL reply rather
#   than an empty one -- the common case for a build that predates the query.
